# PRD F2 — 결정적 보안 스크린 (LLM 없음)

## 목표
LLM을 부르기 **전에**, 결정적 규칙으로 위험 신호를 뽑는다. 악성 판정의 소유권은
이 계층에 있다.

## 근거
`docs/PHASE1-EVIDENCE.md` D-3: 씨앗은 악성 판정을 LLM 단일 호출에 맡긴다. 모델이
작으면(1.5b) 깨끗한 코드의 64%를 악성으로 판정하고 `security_flag`와
`security_reason`이 서로 모순된다. 7b·32b에서는 0%지만, **씨앗은 어느 모델이 쓰일지
강제하지 않는다.**

## 요구사항
1. GitHub API 메타데이터만으로 판정 (clone 불필요)
2. 신호: 설치 스크립트(`curl|sh` 패턴), 난독화(base64 blob·긴 hex), 네트워크 호출
   대상, 의존성 매니페스트의 알려진 악성 패키지명, postinstall 훅
3. 각 신호는 **어떤 파일 어느 줄**에서 왔는지 인용한다. 인용 없는 신호는 버린다
4. 출력은 `{signals: [...], severity: none|low|high}` — 불리언 하나로 뭉개지 않는다

## AC (기계 판정)
- [ ] 알려진 깨끗한 샘플 10개에서 `severity != none` 0건
- [ ] 알려진 악성 패턴 샘플(설치 스크립트·난독화·postinstall) 각각을 잡는 테스트
- [ ] 모든 신호가 `path#line` 인용을 갖는다. 인용 없는 신호를 만들면 테스트 실패
- [ ] LLM 호출 0회 — 이 모듈은 네트워크·모델을 부르지 않는다
