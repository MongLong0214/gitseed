# ADR-0002: v0.1.0 범위 — 무엇을 넣고 무엇을 자르는가

- Status: Accepted (2026-07-26)

## Context

씨앗은 993줄에 테스트 0·CI 0·라이선스 없음이다. 재구축은 "같은 기능을 더 크게"가
아니라 **증거를 낼 수 있는 최소 제품**이어야 한다. 조용한 누락은 금지이므로 자른
것은 전부 Backlog 이슈로 남긴다(공장 불변식 4).

## Decision — v0.1.0 에 넣는 것

| 계층 | 내용 |
|---|---|
| **L0 수집** | GitHub Search로 후보 수집. **레이트리밋 처리 필수**(씨앗에 0건) |
| **L1 다이제스트** | clone 없이 GitHub API로 파일 목록·README·매니페스트만. 얕은 clone은 선택 |
| **L2 결정적 스크린** | 의존성·네트워크 호출·난독화·설치 스크립트를 **정규식·AST로** 판정. LLM 없음 |
| **L3 모델 채점** | 로컬 LLM으로 idea·skill·description. **기동 시 계약 준수 스모크 테스트 통과 필수** |
| **L4 리뷰 큐** | 근거가 붙은 랭킹 목록. 사람이 건건이 승인해야 외부 행동 발생 |
| **L5 기록** | 승인·거부와 그 근거를 CommitLore 트레일러로 남김 |

## Decision — 핵심 불변식

1. **모델을 검증 없이 신뢰하지 않는다.** 기동 시 알려진 깨끗한 샘플과 알려진 악성
   샘플로 스모크 테스트. 실패하면 L3를 끄고 L2만으로 동작한다(기능 저하, 무결성 유지).
   근거: 1.5b에서 깨끗한 코드 오탐 64%, 7b·32b에서 0% (`PHASE1-EVIDENCE.md` D-3)
2. **보안 판정은 L2가 소유한다.** LLM은 의견을 낼 수 있으나 단독으로 악성 판정을
   내리지 못한다. 오탐/미탐 비용이 비대칭이다
3. **산문은 채점 경로에 들어가지 않는다.** 자유서술 필드는 표시용이고 점수에
   기여하지 않는다. 근거: 7b에서도 `description`이 보안 접두어를 흘리는 것을 관측
4. **외부 행동은 사람 승인 뒤에만.** ADR-0001 참조

## Ruled-out

- **저장소 전체 clone** | 씨앗은 clone 후 다이제스트를 만든다. 디스크·시간·악성코드
  실행 위험을 지불하는데, API 메타데이터로 대부분의 신호를 얻을 수 있다. 얕은 clone은
  L2 심층 검사에서만 옵트인
- **채점 결과 캐시 없이 매번 재평가** | 씨앗 방식. 로컬 LLM 호출이 가장 비싼 단계다
- **웹 UI** | v0.1은 CLI만. 리뷰 큐는 터미널에서 충분하다
- **다중 모델 앙상블** | 비용 대비 근거 없음. 단일 모델 + 계약 검증이 먼저다
